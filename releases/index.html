Point an agent at a quick start

Give your coding agent the quick start for the release you work in. To find the release, run matlabRelease in MATLAB.

To let an agent find the quick starts on its own, give it mathworks.github.io/llms.txt. It lists every quick start, the agentic toolkits, and the MathWorks documentation indexes. This page is also available as Markdown. Neither URL changes between releases.
